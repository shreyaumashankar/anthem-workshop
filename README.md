# National Anthem Workshop Project

## Project Description
This project is part of a Git and GitHub practice workshop.
It demonstrates collaborative development using Git branches,
commits, merges, and conflict resolution.

## Features
- Flask web application
- National Anthem of India webpage
- Anthem text file
- Git branching and merging practice
- Merge conflict creation and resolution

## Technologies Used
- Python
- Flask
- HTML
- Git
- GitHub

## Project Structure

anthem-workshop/
- README.md
- anthem.txt
- app.py
- templates/
  - index.html

## How to Run

1. Install Flask:

   python3 -m pip install --user flask

2. Start the application:

   python3 app.py

3. Open a browser at:

   http://localhost:5000

## Git Practice
- Repository creation and publishing
- Clone, push, and pull
- Feature branch creation
- Branch merging and deletion
- Merge conflict resolution
